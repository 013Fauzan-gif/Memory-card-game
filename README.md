# Kartu Memori

Permainan mencocokkan kartu di browser. Ada 8 pasang, total 16 kartu. Semuanya tertutup di awal dan diacak setiap permainan baru. Pemain membuka dua kartu setiap langkah. Jika gambarnya sama, kartu tetap terbuka. Jika berbeda, keduanya tertutup lagi setelah jeda singkat.

## Fitur

- 16 kartu (8 pasang) dengan urutan acak setiap permainan
- Pasangan yang sama tetap terbuka, pasangan yang berbeda tertutup lagi
- Papan terkunci sampai dua kartu selesai dibandingkan
- Penghitung langkah dan waktu
- Tampilan menang yang menampilkan langkah dan waktu
- Tombol main lagi
- Rekor langkah terbaik tersimpan di browser lewat localStorage

## Cara menjalankan

1. Buka folder `Kartu Memori`.
2. Klik dua kali `index.html`, atau seret berkas itu ke jendela browser.
3. Tidak perlu server, instalasi, atau koneksi internet.
